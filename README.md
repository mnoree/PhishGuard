# PhishGuard — Academic Demonstration

PhishGuard is a frontend-based academic demonstration platform designed to simulate cybersecurity awareness scenarios, particularly phishing and social-engineering attacks, in a controlled and safe environment.

The project demonstrates how simulated security scenarios can be used to help users recognize suspicious behavior, understand common social-engineering techniques, review their actions, and receive relevant security-awareness training.

## Core Concept

PhishGuard follows a simulated security-awareness workflow:

Admin
→ Create and manage scenarios
→ Create campaigns
→ Assign simulations to users
→ User completes a simulated scenario
→ User actions are recorded locally
→ Results and behavioral insights are generated
→ Relevant training is recommended
→ Administrators can review reports and progress

The platform separates the administrative experience from the user experience and demonstrates how simulation, behavioral tracking, results, and training can work together as one awareness workflow.

## Public Demo

This repository contains the public demonstration version of PhishGuard.

The demo is designed for academic presentation, evaluation, and demonstration of the project's core concepts.

> **Safety Notice:** This is a simulated environment. It does not send real emails, SMS messages, or phone calls, and it does not collect or transmit real account credentials.

No real external communication or credential harvesting is performed.

## Demo Access

The public demonstration provides role-based demo access:

- **Admin Demo** — administrative dashboard, campaigns, scenarios, users, reports, and settings
- **User Demo** — simulations, results, training, and account activity

No real passwords are required for the public demonstration.

## Data & Privacy

The public demonstration operates entirely on the frontend.

Demo data and simulation activity are stored locally in the browser using LocalStorage.

The public demo does not require real user credentials and does not transmit simulation data to a real phishing infrastructure.

## Project Scope

PhishGuard is an academic graduation-project demonstration.

It is intended to demonstrate cybersecurity awareness concepts, simulated social-engineering scenarios, behavioral tracking, reporting, and security-awareness training.

It is not intended for real-world phishing campaigns, credential harvesting, unauthorized testing, or malicious activity.
